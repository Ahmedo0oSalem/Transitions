# Evaluation Metrics for Formations

## Objective

Calculate team evaluation metrics while the team is playing in a specific formation and analyse how these metrics vary across different formations.

## Metrics to Explore

- Pitch Control
- OBSO (Off-Ball Scoring Opportunity)
- DAS (Dangerous Attacking Space)

## Tasks

- Read the papers or documentation describing each metric and understand the underlying methodology.
- Identify the data required to compute each metric (e.g., tracking data, player positions, ball position).
- Find existing implementations or libraries and learn how to run them on tracking data.
- Validate the outputs by testing the metrics on sample match data.
- Integrate the metrics with the formation detection pipeline so they can be computed for time periods where a specific formation is detected.
- Compare and analyse the resulting metric values across different formations.
